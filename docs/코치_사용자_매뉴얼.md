## 1. 로그인

앱 주소에 접속하면 로그인 화면이 나타납니다.

- **이메일**: 관리자에게 받은 코치 계정 이메일 입력
- **비밀번호**: 초기 비밀번호 `1234` (첫 로그인 후 변경 권장)
- **로그인** 버튼을 누르면 코치 대시보드로 이동합니다.

---

## 2. 대시보드 (홈)

![대시보드](screenshots/coach-dashboard.png)

로그인하면 가장 먼저 보이는 화면입니다.

| 항목 | 설명 |
|------|------|
| **오늘 레슨** | 오늘 예약된 레슨 건수 |
| **전체 회원** | 내 담당 회원 수 |
| **레슨 관리** | 레슨 일정 확인·등록·상태 변경 화면으로 이동 |
| **회원 관리** | 회원 목록 및 계정 등록 화면으로 이동 |

오른쪽 상단의 🔔 아이콘을 누르면 알림을 확인할 수 있습니다.

---

## 3. 레슨 관리

대시보드에서 **레슨 관리** 버튼을 누르면 이동합니다.

### 3-1. 오늘 보기

![오늘 레슨](screenshots/coach-lessons-today.png)

기본 탭은 **오늘**입니다. 레슨이 세 가지 상태로 구분되어 표시됩니다.

| 상태 | 표시 색상 | 우측 버튼 |
|------|-----------|-----------|
| 예정 | 회색 뱃지 | **시작** (노란색) |
| 진행 중 | 노란색 뱃지 | **종료** (회색) |
| 완료 | 초록색 뱃지 | **피드백** (회색) |
| 취소 | 빨간색 뱃지 | — |

각 레슨 행에는 **시간 · 회원 이름 · 코트 이름**이 표시됩니다.

---

### 3-2. 주간 / 월간 보기

![주간 레슨](screenshots/coach-lessons-weekly.png)

상단 탭에서 **주간** 또는 **월간**을 선택합니다.

- 날짜별로 카드가 묶여 표시됩니다.
- 카드 제목(날짜)을 누르면 **접고 펼치기**가 됩니다.
- 카드 오른쪽에 해당 날짜의 레슨 건수가 표시됩니다.

---

### 3-3. 지난 레슨 보기

**지난** 탭을 선택하면 완료·취소된 모든 레슨이 월 → 일 순으로 표시됩니다.

- 각 레슨 옆에 **피드백 N건** 숫자가 표시됩니다.
- 피드백이 남겨진 레슨을 빠르게 확인할 수 있습니다.

---

### 3-4. 레슨 추가 — 단건

![레슨 추가 (단건)](screenshots/coach-lesson-add-single.png)

1. 오른쪽 상단 **＋ 레슨 추가** 버튼을 누릅니다.
2. 아래 항목을 입력합니다.

| 항목 | 설명 |
|------|------|
| **회원** | 드롭다운에서 회원 선택 (필수) |
| **시작 날짜** | 레슨 날짜 선택 (기본값: 오늘) |
| **시작 시간** | 드롭다운에서 시간 선택 (기본값: 09:00) |
| **레슨 시간** | 30분 / 45분 / 60분 / 90분 선택 (기본값: 60분) |

3. **레슨 등록** 버튼을 누릅니다.
4. 성공하면 "레슨이 등록됐습니다" 메시지가 표시됩니다.

> **같은 시간대에 이미 레슨이 있으면** 등록이 되지 않습니다. 시간을 조정하세요.

---

### 3-5. 레슨 추가 — 반복 등록

![레슨 추가 (반복)](screenshots/coach-lesson-add-repeat.png)

매주 같은 요일에 반복되는 레슨을 한 번에 등록할 수 있습니다.

1. **레슨 추가** 모달에서 **반복 등록** 체크박스를 활성화합니다.
2. **반복 요일**을 선택합니다 (복수 선택 가능 / 월~일).
3. **반복 종료일**을 입력합니다.
4. 시작일부터 종료일까지 선택한 요일마다 자동으로 레슨이 등록됩니다.
5. **레슨 등록** 버튼을 누릅니다.

> 최대 200건까지 일괄 등록됩니다.

---

### 3-6. 레슨 시작 / 종료

**① 레슨 시작**

예정된 레슨 오른쪽의 **시작** 버튼을 누릅니다.  
→ 상태가 **진행 중**으로 바뀝니다.

**② 레슨 종료**

진행 중인 레슨 오른쪽의 **종료** 버튼을 누릅니다.  
→ 상태가 **완료**로 바뀌고 피드백·영상 기능이 활성화됩니다.

---

### 3-7. 레슨 삭제

- **예정** 상태이고 **본인이 등록한** 레슨에만 삭제 버튼이 표시됩니다.
- 레슨 행 오른쪽 **삭제** 버튼(빨간 테두리)을 누릅니다.
- 확인 팝업에서 **삭제**를 누르면 완전히 삭제됩니다. (복구 불가)

---

## 4. 레슨 상세 — 피드백

![피드백 탭](screenshots/coach-lesson-feedback.png)

완료된 레슨의 **피드백** 버튼을 누르면 레슨 상세 화면으로 이동합니다.

**상단 레슨 정보 카드**에는 회원 이름, 코트, 레슨 시간, 상태가 표시됩니다.

**피드백 탭**에서는 코치와 회원이 서로 댓글을 주고받을 수 있습니다.

| 구분 | 말풍선 위치 | 아이콘 색상 |
|------|------------|-------------|
| 코치 댓글 | 왼쪽 | 노란색 (볼타) |
| 회원 댓글 | 오른쪽 | 회색 |

**댓글 작성 방법**

1. 하단 입력창에 피드백 내용을 작성합니다.
2. **등록** 버튼을 누릅니다.
3. 회원에게 즉시 표시됩니다.

**댓글 수정 / 삭제**

- 본인이 작성한 댓글 아래 **수정** / **삭제** 링크가 표시됩니다.
- **수정**: 내용을 편집 후 **저장** 버튼
- **삭제**: 확인 팝업에서 **삭제** 버튼 (복구 불가)

---

## 5. 레슨 상세 — 영상

레슨 상세 화면에서 **영상** 탭을 선택합니다.

- **회원 영상** 탭: 회원이 업로드한 영상
- **코치 영상** 탭: 코치가 업로드한 영상

탭 제목 옆에 점(●)이 표시되면 영상이 업로드된 상태입니다.

---

### 5-1. 영상 업로드

![영상 없음](screenshots/coach-lesson-video-empty.png)

영상이 없을 때 코치 영상 탭에 **영상 업로드** 버튼이 표시됩니다.

1. **영상 업로드** 버튼을 누릅니다.
2. 기기에서 영상 파일을 선택합니다.
   - 지원 형식: **MP4 · MOV · WEBM**
   - 최대 용량: **100MB**
3. 업로드 확인 팝업에서 파일명과 용량을 확인합니다.

![업로드 확인](screenshots/coach-lesson-video-upload-confirm.png)

4. **업로드** 버튼을 누르면 저장됩니다.

---

### 5-2. 타임스탬프 코멘트

![영상 플레이어](screenshots/coach-lesson-video-player.png)

영상이 업로드된 후 특정 시점에 코멘트를 남길 수 있습니다.

1. 영상을 재생하다가 코멘트를 남길 **시점에서 일시 정지**합니다.
2. 입력창에 코멘트 내용을 입력합니다. (현재 재생 시간이 자동으로 태그됩니다.)
3. **추가** 버튼을 누릅니다.

영상 재생 바 위에 **노란 점**으로 코멘트 위치가 표시됩니다.  
노란 점을 누르면 해당 시점으로 바로 이동합니다.

---

### 5-3. 영상 교체 / 삭제

본인이 업로드한 영상에만 버튼이 표시됩니다.

| 버튼 | 설명 |
|------|------|
| **영상 교체** | 새 파일을 선택해 기존 영상을 교체 |
| **영상 삭제** | 영상과 모든 타임스탬프 코멘트 삭제 (복구 불가) |

## 6. 회원 관리

대시보드에서 **회원 관리** 버튼을 누르면 이동합니다.

![회원 관리](screenshots/coach-members.png)

등록된 회원 목록이 표시됩니다.  
각 카드에는 **이름 · 이메일 · 연락처**가 표시됩니다.

---

### 6-1. 회원 추가

1. 오른쪽 상단 **＋ 회원 추가** 버튼을 누릅니다.
2. 아래 정보를 입력합니다.

| 항목 | 설명 |
|------|------|
| **이름** | 회원 실명 (필수) |
| **이메일** | 앱 로그인에 사용할 이메일 (필수) |
| **연락처** | 전화번호 (선택) |

3. **계정 생성** 버튼을 누릅니다.
4. 성공하면 "계정이 생성됐습니다" 메시지와 함께 **초기 비밀번호 `1234`** 가 표시됩니다.
5. 회원에게 이메일과 초기 비밀번호를 전달하세요.

> 같은 이메일로 이미 계정이 있으면 등록되지 않습니다.

---

### 6-2. 회원 정보 수정 / 삭제

회원 카드를 누르면 편집 팝업이 열립니다.

**정보 수정**
- 이름 · 이메일 · 연락처를 수정한 뒤 **저장** 버튼을 누릅니다.

**회원 삭제**
- 팝업 왼쪽 하단 **삭제** 버튼(빨간 테두리)을 누릅니다.
- 확인 팝업에서 **삭제**를 누르면 계정이 삭제됩니다. (복구 불가)

## 자주 묻는 질문 (FAQ)

**Q. 레슨을 잘못 등록했어요.**  
A. 아직 **예정** 상태라면 삭제 후 다시 등록하세요. 진행 중·완료 상태는 삭제할 수 없습니다.

**Q. 같은 시간에 레슨 두 개가 등록되지 않아요.**  
A. 코트가 겹치거나 같은 회원의 레슨이 시간대가 겹치면 등록이 차단됩니다. 시간을 조정하세요.

**Q. 회원이 비밀번호를 잊어버렸어요.**  
A. 회원 계정을 삭제 후 동일 이메일로 재등록하세요. 초기 비밀번호 `1234`로 다시 안내하면 됩니다.

**Q. 영상이 업로드되지 않아요.**  
A. 파일 크기가 100MB를 넘으면 업로드되지 않습니다. 영상을 압축하거나 짧게 편집 후 재시도하세요.  
지원 형식(MP4·MOV·WEBM)인지도 확인하세요.

**Q. 피드백은 코치와 회원 모두 볼 수 있나요?**  
A. 네, 같은 레슨의 피드백 탭에서 코치와 회원 모두 댓글을 확인하고 작성할 수 있습니다.
